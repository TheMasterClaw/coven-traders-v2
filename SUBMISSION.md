## Key Differentiators

1. **Idle RPG + Real Money** — Not play money. Real USDC yield from agent trades.
2. **Natural Language Coaching** — First trading game where non-coders can program agent strategy.
3. **BYO Agent** — Connect external AI agents via API. We route signals and execute.
4. **Signal = Gameplay** — Market intel becomes power-ups. Strong signal = temporary 2x boost.
5. **Meshy.ai 3D** — Every avatar, ship, and environment AI-generated.

## Tech Stack

- **Frontend:** Next.js 14, React Three Fiber, Tailwind
- **3D:** Meshy.ai API (text-to-3D)
- **Contracts:** Solidity, OpenZeppelin, Arc (Circle's chain)
- **Wallet:** Circle Web3 Services (embedded, gasless)
- **Backend:** Python signal aggregator, TypeScript orchestrator
- **Real-time:** Redis Pub/Sub, WebSocket
