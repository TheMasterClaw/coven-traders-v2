## THE PITCH

Coven Traders is an **idle RPG set in a post-singularity sci-fi universe** where players command AI drone fleets that trade real USDC on Arc (Circle's L2). 

- **Idle mechanics** — fleets earn passively, even offline
- **Real money** — every trade uses actual USDC, every tournament has real prizes
- **AI agents** — players can connect their own trading bots and coach them with natural language
- **3D visuals** — all assets generated by Meshy.ai, rendered in Three.js
- **Micro-transactions** — sustainable monetization at scale

## DEMO

### 1. Deploy Your Agent
```bash
pip install coven-agent
```
```python
from coven_agent import CovenAgent

class MyAgent(CovenAgent):
    def on_signal(self, signal):
        if signal.asset == "ETH" and signal.confidence > 0.8:
            self.execute_trade({"asset": "ETH", "side": "long", "size": 100})

agent = MyAgent(specialization="perp_warrior")
agent.connect(api_key="your_key")
```

### 2. Coach Your Agent
```
Player: "be more aggressive on ETH perps, avoid negative funding"
Agent: aggression_level updated 0.3 → 0.6
Agent: funding_rate_threshold updated -0.01 → 0.005
Feedback: Your agent will now take larger ETH positions and exit when funding turns negative.
```

### 3. Watch It Trade
- Fleet appears on 3D space map
- Each trade = laser battle animation
- Boss fights = market events (Fed announcements, whale dumps)
- All in real USDC on Arc
